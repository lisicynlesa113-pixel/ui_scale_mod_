# UI Scale (Geode)
1. Создай репозиторий на GitHub, залей туда все файлы этого проекта.
2. Вкладка Actions -> Build Mod -> Run workflow.
3. Когда соберётся, внизу страницы запуска в Artifacts скачай .geode.
4. Положи .geode в папку geode/mods в папке с игрой (или перетащи в окно Geode).

Или локально: поставь Geode SDK + CLI, потом `geode build`.
Правь в mod.json "yourname" на свой ник и версию GD в "gd".
